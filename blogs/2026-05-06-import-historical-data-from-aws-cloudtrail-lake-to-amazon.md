Organizations managing workloads on AWS rely on AWS CloudTrail to answer the fundamental questions: Who did what, where, and when? Since January 2022, customers have stored their CloudTrail activity logs in CloudTrail Lake, a managed data lake purpose-built for capturing, storing, querying user and API activity across their AWS environment. As organizations scale across multiple AWS accounts and Regions, security and operations teams face a common challenge: their CloudTrail data lives in isolation from the rest of their operational and security telemetry.
