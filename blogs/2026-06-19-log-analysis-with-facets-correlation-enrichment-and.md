This post introduces advanced capabilities for analyzing logs across multiple log groups in Amazon CloudWatch Log Analytics. Teams working with distributed systems can explore patterns visually using facets, enrich query results with external metadata through lookup tables, create reusable query templates with parameters, correlate data across log groups using JOIN operations and sub-queries, and automate recurring analysis with scheduled queries that deliver results to S3 or EventBridge.
